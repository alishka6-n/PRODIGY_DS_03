# PRODIGY_DS_03

## Task 3: Decision Tree Classifier

### Objective
Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data.

### Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Steps Performed
1. Loaded and explored the dataset
2. Performed data preprocessing
3. Encoded categorical variables
4. Split dataset into training and testing sets
5. Built a Decision Tree Classifier
6. Predicted customer responses
7. Evaluated model accuracy
8. Visualized feature importance

### Key Insights
- Machine learning models can predict customer purchase behavior effectively.
- Feature importance analysis helped identify influential variables.
- Data preprocessing and encoding are essential before training ML models.

### Conclusion
A Decision Tree Classifier was successfully implemented to analyze customer behavior and predict purchase outcomes with good accuracy.
